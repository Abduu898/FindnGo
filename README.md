# FindnGo
 🚗 FindNGo A simple and clean car rental website built with HTML and CSS. Browse cars, check prices, and book your ride — all in one place.

## MVP pages

- `index.html` - Landing page and quick search
- `fleet.html` - Filterable fleet browser with local favorites
- `booking.html` - Client-side booking request flow
- `how-it-works.html` - Product explanation page

The MVP is intentionally front-end only. Car data lives in `mvp.js`, favorites use `localStorage`, and booking submissions show a local confirmation. Replace those pieces with API calls when a backend is ready.

## Preview

From the `FindnGo` folder, run `python3 -m http.server 8000`, then open `http://localhost:8000`.
